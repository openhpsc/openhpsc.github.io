# OpenHPSC

**Open High-Performance Spaceflight Computing**

An open foundation for the computers that will sense, decide, and act in space.

OpenHPSC is a community initiative working toward open-source, high-performance,
fault-tolerant space computing: hardware architectures, real-time software, and
verification evidence that others can inspect and reproduce.

Our first focus is shared requirements and a bounded RISC-V control-subsystem
experiment. Contributions to architecture, RTEMS integration, FPGA prototyping,
fault-injection methods, and documentation are welcome.

- [Read the documentation](https://openhpsc.github.io/)
- [Explore the source](https://github.com/openhpsc/openhpsc.github.io)
- [Propose a contribution](https://github.com/openhpsc/openhpsc.github.io/issues)

Status: definition phase. OpenHPSC is independent of NASA, JPL, Microchip, and
SiFive; no qualified hardware or radiation-test results are currently claimed.
